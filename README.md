# 🎓 Adaptive-Assessment-Platform 2.0

## MERN Stack App

An intelligent assessment system designed to create, manage, and deliver adaptive tests.
The platform supports multiple user roles with controlled access, allowing educators to create tests with or without options across different difficulty levels. It also enables automated generation of multiple test variations from selected topics, ensuring academic integrity. Students can take assessments and receive certificates based on their performance.

## 🧠 Features

- 🔐 **Authentication & Security**
  - Secure login and registration  
  - JWT-based authentication  

- 🛡 **Role-Based Access Control**
  - Multiple roles with scoped permissions  
  - Fine-grained control over platform access  

- 👥 **User Management**
  - Create, update, and manage users  
  - Assign roles and control access levels  

- 📝 **Advanced Test System**
  - Create tests with:
    - Multiple-choice questions  
    - Open-ended questions  
  - Support for **3 difficulty levels** per test  

- 📚 **Topic & Curriculum Structure**
  - Supports:
    - Grades 7–11  
    - Attestation  
    - Undergraduate levels  
  - Organized topics with integrated question banks  

- 🔄 **Automated Test Generation**
  - Generate multiple unique test variations from selected topics  
  - Randomized questions and answer options  
  - Designed to prevent cheating (e.g., 20 distinct versions per test)  

- 🎯 **Question Bank**
  - Centralized, topic-based question storage  
  - Enables fast and scalable test creation  

- 🏆 **Certification System**
  - Automatically generate certificates based on test results
